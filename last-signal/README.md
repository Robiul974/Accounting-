# Last Signal

One-button lighthouse survival game. A single `index.html` — no dependencies,
works offline in any browser.

## Play

- **Desktop:** open `index.html` in any browser (double-click).
- **Mobile:** download the file and open it with Chrome/Safari, landscape mode.

| Action | Desktop | Mobile |
|---|---|---|
| Nudge the beam | `SPACE` | tap anywhere |
| Move the keeper | `WASD` / arrows | touch near keeper, drag |
| Pause | `P` / `Y` | `II` button (bottom-right) |
| Sound on/off | `M` | — |

The beam rotates on its own; each tap nudge changes it by a fixed angle with a
new rule every 90-second level (+15°, +30°, -15°, alternate, flip-flop, chaos…).
You can't signal while moving — stand still, your back is to the sea.

## Install as an app (PWA)

Needs an HTTPS origin (GitHub Pages, Netlify, etc.) — `file://` won't register
the service worker. Deploy this folder to any static host, then:

- **Android (Chrome):** menu → *Add to Home screen* / *Install app*.
- **iOS (Safari):** Share → *Add to Home Screen*.

It launches fullscreen (landscape) and works offline via the service worker.

## Build an Android APK

See [`capacitor/README.md`](capacitor/README.md) — Capacitor 6 project with
config, icons and release-signing instructions. On a machine with Node 18+
and Android SDK:

```bash
cd last-signal/capacitor
npm install
npm run copy-game
npx cap add android
npm run apk
```

Debug APK lands at
`capacitor/android/app/build/outputs/apk/debug/app-debug.apk`.
